# `envs/aws/identity` (workspace `aws-identity`)

IAM Identity Center permission sets and account assignments, managed in the already enabled instance from the shared-services delegated-administrator account. It reads the `aws-organization` contract. Most inputs default to a key in `config/landing-zone.yaml`; an explicit variable (tfvars or an HCP Terraform workspace variable) wins over the config file. The description of each input names its config key. The config keys live under `aws.identity.*`.
