# `envs/aws/network` (workspace `aws-network`)

Shared AWS networking in the network account: Transit Gateway, IPAM, the inspection VPC with Network Firewall, egress, and the Route 53 Resolver. It reads the `aws-organization` contract and publishes the network contract. Most inputs default to a key in `config/landing-zone.yaml`; an explicit variable (tfvars or an HCP Terraform workspace variable) wins over the config file. The description of each input names its config key. The config keys live under `aws.network.*`.
