# `envs/aws/organization` (workspace `aws-organization`)

The AWS organization in the management account: the OU tree, the foundational member accounts, the guardrail policies (SCP, RCP, declarative and tag) and root-access management. It reads no other root and publishes the organization contract that every other AWS root reads. Most inputs default to a key in `config/landing-zone.yaml`; an explicit variable (tfvars or an HCP Terraform workspace variable) wins over the config file. The description of each input names its config key. The config keys live under `aws.*`.
