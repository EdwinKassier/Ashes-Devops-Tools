# `envs/aws/security` (workspace `aws-security`)

The security baseline across the management, security-tooling, log-archive and forensics accounts. It reads the `aws-organization` contract and publishes the security contract. Most inputs default to a key in `config/landing-zone.yaml`; an explicit variable (tfvars or an HCP Terraform workspace variable) wins over the config file. The description of each input names its config key. The config keys live under `aws.*`.
