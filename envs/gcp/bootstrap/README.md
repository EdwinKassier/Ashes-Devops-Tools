# `envs/gcp/bootstrap` (workspace `gcp-bootstrap`)

Phase-0 automation foundation: the admin project, the Terraform admin service account, the per-workspace plan and apply service accounts, and the workload identity pools. It reads no other root and publishes the bootstrap contract that every other GCP root reads. Apply it first, as a human admin. Most inputs default to a key in `config/landing-zone.yaml`; an explicit variable (tfvars or an HCP Terraform workspace variable) wins over the config file. The description of each input names its config key.
