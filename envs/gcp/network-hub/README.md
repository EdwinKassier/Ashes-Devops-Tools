# `envs/gcp/network-hub` (workspace `gcp-network-hub`)

The hub VPC, the DNS anchor, hybrid connectivity (HA VPN and Interconnect) and the hub VPC Service Controls perimeter. It reads the `gcp-organization` and `gcp-projects` contracts and publishes the `hub_network` contract. Apply it last of the control-plane roots. Most inputs default to a key in `config/landing-zone.yaml`; an explicit variable (tfvars or an HCP Terraform workspace variable) wins over the config file. The description of each input names its config key.
