# Breaking-Change Freeze and v0.2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or build to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stop the growth of breaking changes, prove the upgrade from v0.1.0 in a real sandbox, and release v0.2.0 with a filled sandbox upgrade log.

**Architecture:** A committed `.release-freeze` file turns on a commit check that rejects new breaking commits unless they carry a `Freeze-Exception:` trailer. A static address audit and an ordered upgrade checklist make the v0.1.0 to v0.2.0 path reviewable before any apply. The branch then merges to `main`, a release candidate is tagged, the sandbox estate applies v0.1.0 and upgrades to the candidate, and the final tag follows only when the sandbox log is complete.

**Tech Stack:** bash, git, python-hcl2 7.3.1, Terraform 1.17.1, HCP Terraform, GitHub Actions (meta-lint), release-please (manual tag while the release App is missing).

**Source:** [Second re-audit, Recommendation](../../audit/2026-11-13-due-diligence-reaudit-2.md#recommendation): "Freeze breaking changes until a v0.2.0 is cut with a filled sandbox upgrade log."

- One version for the repository; before 1.0 a breaking change bumps the minor version (`docs/policies/versioning-and-compatibility.md`, `bump-minor-pre-major: true` in `release-please-config.json`).

That config uses the `starter` profile with only the `dev` environment, so production-only code paths are not exercised by it today.
- Branch protection on `main` requires no review today, and admin merges need the owner's OK (Phase 3 is still open).

Create `scripts/check-release-freeze.sh`:

```bash
#!/usr/bin/env bash
# Breaking-change freeze. While .release-freeze exists, every commit made after
# the commit that added it, and not yet on <base-ref>, must not be breaking
# (`type!:` / `type(scope)!:` subject or a `BREAKING CHANGE` footer) unless its
# message carries a `Freeze-Exception: <reason>` trailer with a reason.
# Policy: docs/policies/versioning-and-compatibility.md ("Breaking-change freeze").
#
#   scripts/check-release-freeze.sh <base-ref>
set -euo pipefail

if [ "$#" -ne 1 ] || [ -z "$1" ]; then
  echo "usage: $0 <base-ref>   (for example origin/main)" >&2
  exit 2
fi
if [ ! -f .release-freeze ]; then
  echo "check-release-freeze: no freeze (.release-freeze absent)"
  exit 0
fi
git rev-parse --verify --quiet "$1^{commit}" >/dev/null \
  || { echo "check-release-freeze: base ref '$1' not found (fetch it)" >&2; exit 2; }

release="$(sed -nE 's/^release=(.+)$/\1/p' .release-freeze)"
start="$(git log --diff-filter=A --format=%H -1 -- .release-freeze)"
[ -n "${start}" ] || { echo "check-release-freeze: .release-freeze is not committed" >&2; exit 2; }

bad=()
while IFS= read -r sha; do
  [ -n "${sha}" ] || continue
  msg="$(git log -1 --format=%B "${sha}")"
  if printf '%s\n' "${msg}" | grep -Eq '^[a-z]+(\([^)]*\))?!:|^BREAKING[ -]CHANGE'; then
    if ! printf '%s\n' "${msg}" | grep -Eq '^Freeze-Exception:[[:space:]]*[^[:space:]]'; then
      bad+=("$(git log -1 --format='%h %s' "${sha}")")
    fi
  fi
done < <(git rev-list "${start}..HEAD" --not "$1")

if [ "${#bad[@]}" -gt 0 ]; then
  echo "Breaking-change freeze until ${release:-the next release} (.release-freeze)." >&2
  echo "These commits are breaking and have no 'Freeze-Exception: <reason>' trailer:" >&2
  printf '  %s\n' "${bad[@]}" >&2
  echo "Make the change non-breaking (deprecate first), or add the trailer with the approval." >&2
  exit 1
fi
echo "check-release-freeze: OK (freeze until ${release:-the next release})"
```

Create `scripts/check-address-moves.py`:

```python
#!/usr/bin/env python3
"""List resource and module-call addresses removed between two git refs that no
`moved` block, `removed` block or allowlist entry covers.

Each directory under modules/ and envs/ that holds top-level *.tf files is one
Terraform module. Only static addresses (`type.name`, `module.name`) are
compared; changes to count or for_each keys are not visible here.

    python3 scripts/check-address-moves.py --from v0.1.0 --to HEAD \
        --allowlist scripts/address-moves-allowlist.txt

Allowlist lines: `<module dir> <address> <UPGRADING heading>`; `#` starts a
comment line. Exit 1 when an uncovered removal exists.
"""
import argparse
import subprocess
import sys

import hcl2

ROOTS = ("modules/", "envs/")


def git(*args):
    return subprocess.run(["git", *args], check=True, capture_output=True, text=True).stdout


def tf_files(ref):
    out = git("ls-tree", "-r", "--name-only", ref, "--", *ROOTS)
    files = {}
    for path in out.splitlines():
        if not path.endswith(".tf") or "/.terraform/" in path:
            continue
        parts = path.split("/")
        if "tests" in parts or "examples" in parts:
            continue
        files.setdefault("/".join(parts[:-1]), []).append(path)
    return files


def strip(expr):
    expr = str(expr).strip()
    if expr.startswith("${") and expr.endswith("}"):
        expr = expr[2:-1]
    return expr.strip()


def label(key):
    # python-hcl2 7.x may keep the quotes on block labels; metadata keys start with "__".
    return str(key).strip('"')


def labels(mapping):
    return [label(k) for k in mapping if not str(k).startswith("__")]


def parse(ref, paths):
    addrs, moved_from = set(), set()
    for path in paths:
        try:
            doc = hcl2.loads(git("show", f"{ref}:{path}"))
        except Exception as exc:  # report and continue; one bad file must not hide others
            print(f"warning: cannot parse {ref}:{path}: {exc}", file=sys.stderr)
            continue
        for block in doc.get("resource", []):
            for rtype in labels(block):
                named = block.get(rtype, block.get(f'"{rtype}"', {}))
                for name in labels(named):
                    addrs.add(f"{rtype}.{name}")
        for block in doc.get("module", []):
            for name in labels(block):
                addrs.add(f"module.{name}")
        for kind in ("moved", "removed"):
            for block in doc.get(kind, []):
                if "from" in block:
                    moved_from.add(strip(block["from"]))
    return addrs, moved_from


def covered(addr, moved_from):
    for src in moved_from:
        if src == addr or src.startswith(addr + "[") or src.startswith(addr + "."):
            return True
    return False


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--from", dest="src", required=True)
    ap.add_argument("--to", dest="dst", default="HEAD")
    ap.add_argument("--allowlist", required=True)
    args = ap.parse_args()

    allowed = set()
    with open(args.allowlist, encoding="utf-8") as fh:
        for line in fh:
            line = line.strip()
            if line and not line.startswith("#"):
                parts = line.split(None, 2)
                if len(parts) >= 2:
                    allowed.add((parts[0], parts[1]))

    old, new = tf_files(args.src), tf_files(args.dst)
    problems = []
    for mod in sorted(old):
        if mod not in new:
            if (mod, "*") not in allowed:
                problems.append(f"{mod}: module directory removed")
            continue
        old_addrs, _ = parse(args.src, old[mod])
        new_addrs, moved_from = parse(args.dst, new[mod])
        for addr in sorted(old_addrs - new_addrs):
            if not covered(addr, moved_from) and (mod, addr) not in allowed:
                problems.append(f"{mod}: {addr}")

    print("Static addresses only: count/for_each key changes are not checked.")
    if problems:
        print(f"{len(problems)} removed address(es) with no moved/removed block or allowlist entry:")
        for p in problems:
            print(f"  {p}")
        return 1
    print("check-address-moves: OK")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```
